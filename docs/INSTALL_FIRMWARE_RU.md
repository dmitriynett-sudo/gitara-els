# Готовая прошивка

[Скачать предварительный выпуск V11 DEMO](https://github.com/dmitriynett-sudo/gitara-els/releases/tag/v11-demo-rc1) для Waveshare RP2350-Touch-LCD-2. Файл: `GITARA_V11_DEMO_RP2350.uf2`, размер 355 840 байт.

SHA-256:

```text
9eaaeb09e14cf221f19d0ea047f0a47c78d621aa1ab1111ba0a7404f42c13182
```

Владелец подтвердил работу деморежима на второй плате. Перед работой требуется проверка подключения и настройки своего станка.

## Перед установкой

- Проверьте название поддерживаемой платы и требования конкретного релиза.
- Запишите настройки механики и драйвера. Формат настроек и лицензии V11 не менялся при включении демосборки; после установки проверьте сохранённые значения. Ранее активированная совместимая плата может сразу показать ACTIVE.
- Остановите станок и исключите неожиданное движение: переводите плату в режим загрузки только при обесточенном силовом драйвере.

## Порядок установки

1. Скачайте именно файл `.uf2` для своей платы из Releases и сравните SHA-256 с опубликованным значением.
2. Переведите плату в USB-режим BOOT согласно её паспорту. Не меняйте подключение питания или BOOT наугад.
3. Скопируйте UF2 на появившийся загрузочный USB-диск. После записи плата обычно перезапускается.
4. Проверьте версию, механические настройки, SIMULATOR OFF и статус активации. Выполните проверку направления, перемещения и лимитов без резания.

Не загружайте UF2 для другой платы. Не применяйте полное стирание flash без понимания последствий для сохранённых настроек и активации.

## Активация

Откройте SETUP → REGISTER, сообщите продавцу DEVICE ID, получите код для этой платы и введите все восемь цифр, включая начальные нули. ACTIVE означает принятую активацию. TEST FULL означает тестовую сборку с открытыми функциями и не является обычной демонстрационной сборкой для продажи.
