# ELS Pi R6 - схема и печатная плата

Несущая плата 58 x 38 мм для Waveshare RP2350-Touch-LCD-2. Два медных слоя.

[Скачать полный комплект KiCad](ELS_R6_KiCad.zip) · [Принципиальная схема, PDF](ELS_R6_Schematic.pdf)

В архиве: проект KiCad 10, четыре листа схемы, печатная плата, библиотеки символов и посадочных мест, список деталей, монтажные карты и Gerber.

Для открытия распакуйте весь архив и откройте KiCad/ELS_R6.kicad_pro.
